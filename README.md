# Scholarship Scout

A small, self-contained scholarship chatbot prototype. It runs in a browser without a build step, API key, or server.

## Run locally

Open `index.html` in a browser.

## What it does

- Answers common scholarship questions with built-in general guidance.
- Offers an optional guided profile flow to create focused scholarship search links.
- Provides reminders to confirm current requirements, amounts, and deadlines with the official scholarship provider.

This prototype does not use an AI model or a live scholarship database. It cannot confirm eligibility or current award details. Search links open Google with the search terms shown in the chatbot. The app does not save the profile or send it anywhere unless a user opens one of those search links.

## Upload to a different GitHub account

1. Sign in to the GitHub account that should own the repository.
2. Create a new repository.
3. Upload `index.html` and `README.md` from this folder to the repository root and commit the files.
4. To publish it as a website, open the repository’s **Settings → Pages** and choose **Deploy from a branch**, then select the default branch and `/(root)`.

GitHub’s instructions: [Add a file to a repository](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file) · [Configure a GitHub Pages publishing source](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
